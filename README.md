# From Italy to Chicago — Interactive Timeline

A single-file HTML/CSS/JavaScript prototype for a student interactive explainer.

## Preview locally
1. Open this folder in VS Code.
2. Open `index.html`.
3. Use the Live Server extension (if installed), or open `index.html` in your browser.
4. Click the five timeline markers and test at desktop and mobile widths.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `italian-food-timeline`).
2. Upload `index.html` to the repository's root.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. After GitHub Pages publishes it, use the public URL (usually `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`).

## Before submitting
- Verify each historical claim with reliable sources.
- Add actual source links to the source area for each period.
- Add optimized images that you have permission to use. Store them in an `images/` folder and update the `image` fields in the `eras` array (for example, `images/taylor-street.jpg`).
- Add meaningful alt text in each `alt` field and a source/credit in each `credit` field.
- Test keyboard use, contrast, mobile layout, and the published public URL.
- Disclose AI assistance and third-party code according to your instructor's requirements.

The broad date ranges are working placeholders, not a fully verified historical chronology.
